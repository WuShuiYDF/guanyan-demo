研 屿

于信息汪洋，筑备考之屿

考研只能报一所院校、一个专业，没有平行志愿的安全网。 研屿将全网舆情量化为可比较的竞争信号，通过多 Agent 协作帮你做个性化分析—— 不只是查数据，而是帮你看清这一次不可逆的选择。

THE PROBLEM
考研择校，本质上是一次不可逆的单次博弈
你只能报考一所院校、一个专业。而互联网上的信息洪流，让这次选择变得更加艰难。

噪声淹没信号

知乎、贴吧、小红书、微博……7 个平台每天数万条讨论，「劝退」「血泪教训」与「冲就完了」交织在一起，真假难辨。

观点相互矛盾

同一个院校专业，有人说是「捡漏宝藏」，有人说是「卷王地狱」。去年的经验帖可能完全不适用于今年。

决策孤立无援

现有工具只给你查数据——分数线、报录比、招生人数。但数据不等于判断，你需要的不是另一个查询框，而是一个能帮你做分析的伙伴。

沉潜自习室

FOCUS STUDY

番茄钟 + AI 学伴 + 沉浸式场景。选择你的备考场景，在专注中与 AI 讨论疑难，和同场研友互相可见——一个人备考，不是一座孤岛。

MULTI-AGENT SYSTEM
四角色 Agent 协作架构
不是简单的「问 AI 一个问题等回答」。四个专业化 Agent 各司其职， 像一支分析团队一样协作，甚至互相辩论——确保你看清盲区。
规划 Agent PLANNING
接收你的问题和画像，制定分析计划：先查什么、再查什么、是否需要触发辩论。 它理解舆情日历——知道现在是基础阶段还是冲刺阶段，不同阶段关注不同信号。
分析 Agent ANALYSIS
通过 Function Calling 自主调用数据工具：查询热度、采样原帖、对比跨平台差异、 计算信息差。它不只看预计算指标——能从原始数据中发现设计者没有预料到的信号。
辩论 Agent DEBATE
三位顾问围绕分析结果展开对抗式辩论，经过 1-2 轮交锋后收敛到综合结论。 辩论过程透明可见，让你看到每种判断背后的逻辑。
激进派顾问

倾向「冲一冲」，聚焦机会信号。当别人看到风险时，他看到被低估的价值。

保守派顾问

倾向「稳一稳」，聚焦风险信号。复试公平性、舆论劝退、缩招趋势——他不放过任何隐患。

数据派顾问

没有预设立场，纯粹数据驱动。往往能发现激进派和保守派都忽略的第三维度信号。

报告 Agent REPORT
综合所有分析结论 + 辩论结果 + 你的画像，生成个性化择校报告。 每个数据点标注可信度层级，从不给出绝对判断—— 提供框架分析（风险 + 机会），把决策权留给你。

CREDIBILITY
每个数据点，都标注可信度
不是所有数据生而平等。官方分数线和论坛帖子的情绪分析，可信度天差地别。 研屿对每一个数据点标注三级可信度——让你清楚知道什么可以信赖，什么只是参考。

T1 官方数据

研招网分数线、院校官方录取数据。最高可信度，直接引用。

T2 半官方聚合

考研帮整理数据、中国教育在线汇编。经过二次加工，基本可靠。

T3 舆情推断

从论坛讨论量、情绪分析中推导的指标。有参考价值，但需结合判断。

DATA FLYWHEEL
数据飞轮：你的授权，惠及所有人
研屿有一套独特的数据共建机制。你授权绑定平台账号后，系统从你的视角采集公开数据， 汇入公共数据库——每个新加入的用户都让数据库更完整，让所有人的分析更准确。
01

授权绑定

扫码绑定知乎、小红书、微博、B 站、抖音、百度贴吧 6 大平台账号。仅获取公开可见的考研相关讨论，不读取私信或个人信息。

02

自动采集

系统定期从你的视角抓取公开讨论帖，经 NLP 流水线处理：情感分析、实体识别、话题分类，提取结构化信号。

03

汇入公共池

采集数据经去重、清洗后汇入共享数据库。你的授权不会暴露身份，只贡献数据信号——隐私安全，集体受益。

04

全员受益

数据飞轮越转越快：参与用户越多，数据库越完整，舆情分析越准确。每一个新加入的人都在让所有人的决策更有依据。
